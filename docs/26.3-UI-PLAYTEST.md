# Minecraft 26.3 UI fix candidate

This candidate changes the shared Lite/Plus first-person viewmodel bridge to apply configured offsets, rotation, and scale at each item/hand submission. It also routes custom inventory equipment slots to `/equipment` and vanilla armor slots to `/wardrobe`, including empty slots. The color picker now leaves room for its alpha slider and buttons, and Escape closes it on the first press. Arrow keys can adjust hue and brightness.

`gradlew build` passes, including the Plus tests, dungeon boundary check, and Lite JAR verifier. These checks do not prove in-game input or first-person rendering. Before replacing the current 26.3 playtest JARs, close the running 26.3 Test instance and validate each edition separately:

1. Open a module color picker; click SV, hue, RGBA sliders, Apply, Cancel, Reset, Back, and press Escape while editing and while idle.
2. Enable View Model with a held item; vary X/Y/Z offsets, rotation, and scale. Check main and offhand as well as the empty hand setting.
3. Open the custom inventory on SkyBlock; click the R button, empty pet slot, all four equipment slots, and all four armor slots. Confirm the intended menus open without moving items.
4. Toggle the HUD Title setting and change Scale on a HUD that has multiple visible lines; reopen the dashboard and restart Minecraft to check persistence. Test the module's custom name setting separately.

The preceding `playtest-26.3` release remains the baseline until this runtime matrix passes. The candidate binaries are in the local `Playable Jars/26.3 UI fix candidate` folder.
